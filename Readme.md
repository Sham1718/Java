#  How to Run

## Backend Projects

Navigate to the desired backend project.

```bash
cd Blog
```

or

```bash
cd NotesManager
```

or

```bash
cd TaskApi
```

Run the application.

```bash
mvn spring-boot:run
```

---

## Frontend Projects

Navigate to the frontend project.

```bash
cd NoteFrontend
```

or

```bash
cd Task
```

Install dependencies.

```bash
npm install
```

Run the application.

```bash
npm run dev
```
